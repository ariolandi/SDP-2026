## STL Vector

#### Употреба

Последователна хомогенна структура от данни, дефинираща редица от произволен тип с променлива дължина. Поддържа итератори.

- библиотека vector
- std::vector<T>


#### Основни операции
- преоразмеряване
```c++
arr.resize(n); // променя размера на N елемента със стойност по подразбиране или досегашна стойност
arr.resize(n, value); // променя размера на N елемента със стойност value
```
- добавяне на елемент
```c++
arr.push_back(value); // добавя се копие на value в края на вектора
arr.emplace_back(value); // добавя се референция към value в края на вектора
arr.insert(positionIt, value); // вмъква елемент със стойност value на позицията, сочена от итератора positionIt
```
- изтриване на елементи
```c++
arr.pop_back(); // изтрива последния елемент
arr.clear(); // изтрива всички елементи
arr.erase(positionIt); // изтрива елемента, сочен от итератора positionIt
```
- размер
```c++
arr.size();
arr.capacity();
```

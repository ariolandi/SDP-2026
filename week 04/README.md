## Едносвързан списък. Итератори

### Едносвързан списък

#### Дефиниция

Линейна динамична структура от данни, която се състои от поредица от свързани помежду си елементи, наричани възли.

При едносвързаност, посоката на връзката и движението са само към следващият елемент без връщане назад. 

```
l = x -> y -> z
```

#### Основни операции

- Добавяне на елемент в края на списъка (push_back)
```
l = x -> y -> z   --l.push_back(w)--> l = x -> y -> z -> w
```

- Добавяне на елемент в началото на списъка (push_front)
```
l = x -> y -> z   --l.push_front(w)--> l = w -> x -> y -> z
```

- Премахване на елемент от края на списъка (pop_back)
```
l = x -> y -> z   --l.pop_back()--> l = x -> y
```

- Премахване на елемент от началото на списъка (pop_front)
```
l = x -> y -> z   --l.pop_front()--> l = y -> z
```

- Достъпване на елемента в началото на списъка (front)
```
l = x -> y -> z    --l.front()-->  x
```


- Достъпване на елемента в началото на списъка (back)
```
l = x -> y -> z    --l.back()-->  z
```

- Проверка дали списъкът е празен (empty)
```
l = x   --l.empty()-->  false

l = _   --l.empty()-->  true
```

#### STL::forward_list 

##### Специфики
- липсват методите `pop_back`, `push_back` и `back`
- налични допълнителни методи:
  - insert_after(pos, x) - Добавя нов елемент със стойност x след позиция pos, където pos е итератор
  - erase_after(pos) - Изтрива елемента след позиция pos, където pos е итератор
  - remove(x) - Изтрива всички елементи със стойност x
  - remove_if(condition) - Изтрива всички елементи, отговарящи на condition (булева функция)


### Итератори

#### Дефиниция

Указател към елемент в свързана структура от данни, позволяваща нейното обхождане.

```std::forward_list<T>::iterator`


Ако е даден едносвързан списък `std::forward_list<T> l`:
- `begin()` - итератор към началото на списъка
- `end()` - итератор към края на списъка (след последния елемент)
- достъпването на стойността в l, сочена от итератор it се осъществява чрез `*it`

##### Пример
```c++
std::forward_list<int> l = {10, 20, 30, 40};

for (std::forward_list<int>::iterator it = l.begin(); it != l.end(); ++it) {
    std::cout << *it << std::endl;
}
```

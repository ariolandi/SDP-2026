## Свързано представяне на структури от данни. Стек. Standart Template Library

### Свързано представяне на структури от данни

#### Дефиниция

Представяне, основано на възли и връзки между тях. 

```C++
template <typename T>
struct Node {
    T value;        // стойност на възела
    Node<T>* next;  // указател към следващия елемент

    Node(const T& value, Node<T>* next=nullptr): value(value), next(next) {}
};
```
#### Свързано срещу динамично срещу статично представяне

| Представяне  |  Размер   | Подредба на елементите   | Особености в архитектурата         |
| ------------ | --------- | ------------------------ | ---------------------------------- |
| Статично     | фиксиран  | последователни в паметта | статичен масив с фиксиран размер   |
| Динамично    | променлив | последователни в паметта | динамичен масив с променлив размер |
| Свързано     | променлив | разпръснати из паметта   | представяне чрез възли и връзки между тях |


### Структура стек

#### Дефиниция

Линейна структура от данни, следваща принципа LIFO (Last In - Fist out). Характерно е наличието на пряк достъп единствено до върха на на стека, т.е. последният влязъл елемент. 

```
    | x |
s = | y |
    | z |
    |___|
```

#### Основни операции

- Добавяне на елемент на върха на стека (push)

```
                                | w |
    | x |                       | x |
s = | y |  --s.push(w)-->   s = | y |
    | z |                       | z |
    |___|                       |___|
```

- Премахване на елемент от върха на стека (pop)

```
    | x |                     
s = | y |  --s.pop()-->     s = | y |
    | z |                       | z |
    |___|                       |___|
```

- Достъпване на елемента на върха на стека (top)

```
    | x |
s = | y |    --s.top()-->   x
    | z |
    |___|
```

- Проверка дали стекът е празен (empty)
```
    | x |
s = | y |    --s.empty()-->  false
    | z |
    |___|

t = |___|    --t.empty()-->  true
```

### Standart template library (STL)

#### STL::stack

```c++
#inlude<iostream>
#include<stack>

int main() {
    std::stack<int> exampleStack;

    std::cout << exampleStack.empty() << std::endl;

    size_t n;
    std::cin >> n;

    for (size_t i = 0; i < n; ++i) {
        int x;
        std::cin >> x;
        exampleStack.push(x);
    }

    std::cout << exampleStack.empty() << std::endl;
    std::cout << exampleStack.top() << std::endl;

    exampleStack.pop();

    std::cout << exampleStack.top() << std::endl;

    return 0;
}

```
